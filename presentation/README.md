# 시계열 데이터 분석 — 발표자료 (PPT)

`insta_trend` 해시태그를 **시계열 관점**(추세 · 계절성 · 모멘텀 · 예측)으로
분석한 PowerPoint를 코드로 생성합니다. 정적 랭킹만 하던 코어를 "시간 축"으로
확장해, 떠오르는 태그와 식어가는 태그를 조기에 식별하는 것이 목표입니다.

## 결과물

- **`insta_trend_timeseries.pptx`** — 16:9, 14장 슬라이드 (한국어 내레이션)
- `assets/*.png` — 슬라이드에 삽입되는 분석 차트

## 다시 만들기

```bash
pip install -r presentation/requirements.txt
python presentation/build_deck.py     # 차트 + .pptx 를 결정론적으로 재생성
```

> 폰트는 임베드하지 않습니다. 슬라이드는 한글 본문에 *맑은 고딕*을 요청하므로
> 한국어 PowerPoint 환경에서 그대로 열립니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `timeseries_data.py` | 시드 고정 일별 패널 데이터 생성 (level + 추세 + 요일 계절성 + 노이즈) |
| `charts.py` | 시계열 분석 + matplotlib 차트 렌더링 |
| `build_deck.py` | python-pptx 로 슬라이드 조립 |

## 분석 방법

- **이동평균**: 7일·14일 중심 이동평균으로 단기 노이즈 제거
- **시계열 분해**: 가법 모형 `관측 = 추세 + 주간 계절성 + 잔차`
- **계절성**: 요일별 평균 게시량 프로파일
- **모멘텀**: 7일 이동평균을 1주차=100으로 지수화한 성장률 비교
- **예측**: 최소제곱 선형추세 + 요일 계절성을 14일 외삽, 95% 잔차 밴드

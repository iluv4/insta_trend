# 시계열 데이터 분석 — 발표자료 (PPT)

**네이버 데이터랩 실데이터**로 2026년 상반기 한국 해시태그 트렌드를
시계열 이론(정상성 · ACF · 분해 · 예측)으로 분석한 PowerPoint를 코드로
생성합니다. CS 시계열 수업에서 배운 개념을 실데이터에 적용하는 구성입니다.

## 결과물

- **`insta_trend_timeseries.pptx`** — 16:9, 28장 슬라이드 (한국어)
- `assets/*.png` — 슬라이드에 삽입되는 분석 차트 8종
- `naver_datalab_panel.csv` — 2026-06-11(KST) 수집한 일별 검색 관심도 실데이터

## 다시 만들기

```bash
pip install -r presentation/requirements.txt
python presentation/build_deck.py     # 차트 + .pptx 재생성 (CSV 고정 → 결정론적)
```

> 폰트는 임베드하지 않습니다. 슬라이드 본문은 *맑은 고딕*, 차트는
> *나눔고딕*(렌더링 시 필요: `apt install fonts-nanum`)을 사용합니다.

## 분석 방법 (수업 범위)

- **평활화**: 7일·28일 중심 이동평균
- **정상성 진단**: 롤링 평균/표준편차 + 1차 차분 `∇X_t = X_t − X_{t−1}`
- **자기상관**: 표본 ACF `ρ̂(k) = γ̂(k)/γ̂(0)` 직접 구현, 백색잡음 한계 `±1.96/√n`
- **분해**: 가법 모형 `X_t = T_t + S_t + R_t` (추세=이동평균, 계절=요일별 평균)
- **예측**: 최소제곱 선형추세 + 요일 더미 계절성, 14일 외삽, 95% 예측구간
- **모델 비교**: 위 베이스라인 vs `SARIMA(1,1,1)(1,1,1)₇` — 마지막 14일 홀드아웃 백테스트(MAE)로 정확도 비교
- **계정 시뮬레이션**: 가상 계정 일별 도달(추세+주말 계절성+바이럴 이벤트+노이즈)을 분해·예측 (`account_sim.py`, 교육용 합성 데이터)
